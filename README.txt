GEMINI CHAT - PRASHANT

1. Extract this ZIP.
2. Open index.html in your browser.
3. Click API settings (gear), paste your Gemini API key and save.
4. Start chatting.

Chats and API key are stored in localStorage on this browser.
This is a personal-use browser app. Do not deploy it publicly with your API key:
browser-side API keys can be exposed. Use a server-side proxy for public hosting.
