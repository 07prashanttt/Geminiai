Prashant Chat
- Open index.html in your browser or upload all files to GitHub Pages.
- On first load, a setup dialog asks for your Gemini API key. It saves in browser localStorage.
- API setup button in sidebar allows replacement later.
- Gemini API call uses generateContent with x-goog-api-key.
- Do not publish this with an unrestricted key: browser-side keys can be exposed. Configure API key restrictions and quotas.
- Features: chat history, new chat, delete individual chat (top ellipsis), clear history, model selection, copy response, search chat titles, responsive sidebar, Enter send / Shift+Enter newline.
- No claim of external API testing; availability/quota/model access depend on your key and account.
